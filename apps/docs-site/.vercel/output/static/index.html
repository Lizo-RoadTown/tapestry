The problem

Most AI tools solve generation.
Tapestry solves continuity.

The model can write the code. What disappears is everything around it — the context, the reasons, the patterns that made the work good. That loss is where the cost is.

  • 01Every project starts from scratch.
  • 02Useful interactions disappear after the session ends.
  • 03The same workflows get recreated again and again.
  • 04Nobody remembers why things worked.
  • 05Project knowledge is scattered across chats, docs, code, and people.
  • 06Teams can't see how their AI workflows are evolving.

What it does

Capability that accumulates.

Four things, each backed by a mechanism that keeps running across every project.

Observe project evolution

Telemetry · Observatory

Watch how each project's shape changes over time. Raw sessions become coordination episodes — intent, action, friction, structure — so the work is legible, not just logged.

Preserve knowledge

Memory

Context, corrections, and the reasons behind decisions carry between sessions and across projects. The next session starts where the last one left off instead of from zero.

Discover patterns

Observer

The observer reads what's actually happening and surfaces the patterns — what worked, what keeps breaking, where the same correction gets made again. Findings, not raw counters.

Build durable structure

Upskilling · Templates

Repeated work becomes named, reusable skills and templates — available in every project by reference, not copy. Capability compounds instead of being rebuilt each time.

Open platform

Build on open pieces.

Tapestry runs on installable, open components. Adopt them one at a time, in any project — by reference, not copy.

Quickstart

Three commands in.

Install the CLI, wire a project into the platform, and open the console. The agents pick up memory, telemetry, and the discipline rules from there.

Full setup guide →
bash
# install the CLI
$ pipx install tapestry-cli

# wire this project into the platform
$ tapestry onboard

# open the live console
$ tapestry observatory
→ opening https://tapestry-khaki.vercel.app/observatory
