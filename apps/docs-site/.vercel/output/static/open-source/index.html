Start building

Install one piece. Keep your stack.

Adopt the components one at a time, in any project — by reference, not copy. The CLI is on PyPI; the plugins install from the marketplace.

bash
# the CLI — onboard a project, open the console
$ pipx install tapestry-cli
$ tapestry onboard

# the discipline + patterns plugins
$ /plugin marketplace add Lizo-RoadTown/tapestry
$ /plugin install tapestry-discipline@tapestry

View the code. Contribute.
