# Archived Learn pages

These were concept pages on the published docs site (`apps/docs-site`). They were removed from the website on 2026-06-25 when the Learn section was slimmed to what a reader actually needs to understand Tapestry — what it is, how the observer works, the Observatory, and what Tapestry is not.

They're kept here for reference because they describe internal mechanics in detail. They are developer-facing at most; most readers don't need them.

Note: the "project shape" pages (`project-shape.md`, and the shape framing in others) describe a model the operator has since rejected as inaccurate. The accurate framing is: Tapestry is an intelligence that watches across all your projects and turns recurring friction into durable structure. See the Learn pages on the live site for the current model.

These files contain website-relative links (`/explanation/...`, `/start/...`) that no longer resolve, since the pages left the published tree.
